صفحة تحميل تطبيق مدرسة المنارة

محتويات المجلد:
- index.html : صفحة التحميل الرئيسية
- logo.jpg : شعار المدرسة المستخرج من التطبيق
- almanara-school.apk : ملف التطبيق

طريقة النشر على Vercel:
1) فك ضغط الملف المرفق.
2) افتح vercel.com وسجل الدخول.
3) اختر Add New ثم Project.
4) ارفع مجلد الموقع أو اربطه بمستودع GitHub.
5) لا تحتاج إعدادات Build لأن الموقع Static.
6) بعد Deploy سيعطيك Vercel رابطاً عاماً للصفحة.

ملاحظة: ملف التطبيق الحالي اسمه الأصلي app-debug، أي أنه نسخة Debug. يعمل للتجربة والتثبيت اليدوي، لكن للنشر النهائي الأفضل إنشاء APK أو AAB موقّع بنسخة Release.
